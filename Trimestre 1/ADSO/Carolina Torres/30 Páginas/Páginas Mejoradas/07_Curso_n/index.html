Detalles del Curso

Objetivo Principal

Dominar la estructura semántica de HTML5 para crear sitios web profesionales, accesibles y optimizados para SEO desde cero.

Requisitos Técnicos

No requiere experiencia previa. Solo necesitas una computadora con Windows, Mac o Linux y el editor Visual Studio Code instalado.

Perfil del Egresado

Al finalizar, podrás maquetar interfaces complejas, entender la jerarquía de etiquetas y preparar proyectos para ser estilizados con CSS.

Metodología

40 horas de contenido práctico asincrónico. Incluye ejercicios reales, material de lectura PDF y acceso a foros de consulta.
